# <img src="orderpoint.svg" width="25"/> OrderPoint

### **👁️ Overview**
Order Management Web Application - 2026.

<p align="justify">
    OrderPoint is a multi-application order management system designed to streamline customer ordering and beverage service operations. The system includes a customer mobile app that allows users to scan a QR code, browse the menu, and place orders directly from their phones; a bartender web app that receives orders in real time and helps staff manage fulfillment efficiently; and an admin web app that gives the owner full oversight of the entire system, including order activity and operational management. Together, these applications create a fast, connected, and organized ordering experience for both customers and staff.
</p>
